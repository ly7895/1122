# 综测记录

记录综测加分、扣分的手机小应用。每条记录都能写文字说明、贴照片，自动算出「加分合计 − 扣分合计」的当前总分。装到手机主屏幕后像 App 一样全屏打开，没有网络也能用。

## 功能

- 记一笔：填分值、选加分或扣分、写事项和说明，可以带最多 6 张照片
- 照片自动压缩：1280 像素长边，单张约 320KB，直接存在手机里，不需要服务器
- 首页大字显示当前总分，下面是加分合计、扣分合计、记录条数
- 最近六个月的净加分一览，记录按月份分组显示
- 搜索事项、备注、日期；按全部 / 加分 / 扣分 / 有照片筛选
- 编辑和删除：点任意一条记录即可修改，删除前会二次确认
- 导出 JSON 备份（含全部照片）、导出 CSV 表格（可用 Excel / WPS 打开）
- 导入 JSON 备份，换手机、清缓存后可以完整恢复
- 示例数据：第一次打开可以先点「载入示例数据」看看效果

## 文件结构

```
index.html              整个应用（样式和脚本都内联在里面）
manifest.webmanifest    应用名称、图标、启动方式
sw.js                   离线缓存，版本号在文件开头
icons/                  各种尺寸的应用图标
apple-touch-icon.png    iOS 添加到桌面的图标
.nojekyll               让 GitHub Pages 不处理这些文件
tools/make-icons.py     重新生成图标（可选，需要 Pillow）
tools/assemble.py       把 tools 下的分块重新拼成 index.html（可选）
tools/syntax_check.py   检查 CSS / HTML / 脚本的括号是否配对（可选）
```

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库，例如 `zongce-record`，不要勾选初始化 README。
2. 把本文件夹里的**全部内容**（不是文件夹本身）上传到仓库根目录，注意要带上 `icons` 文件夹和 `.nojekyll`。
3. 打开仓库的 **Settings → Pages**，**Source** 选 `Deploy from a branch`，**Branch** 选 `main` 和 `/ (root)`，保存。
4. 一两分钟后访问 `https://你的用户名.github.io/仓库名/`，能看到页面就说明部署成功。

以后修改了 `index.html`，记得把 `sw.js` 开头的版本号改一下（例如 `zongce-rec-v2` → `zongce-rec-v3`），否则手机上可能还在用旧的缓存。

## 装到手机主屏幕

### iPhone（Safari）

1. 用 Safari 打开上面的网址（必须是 Safari，微信里的浏览器不行）。
2. 点底部中间的「分享」按钮。
3. 往下找「添加到主屏幕」，确认名称后点「添加」。
4. 从主屏幕打开，就是全屏没有地址栏的样子。

### 安卓（Chrome / Edge / 系统浏览器）

1. 用 Chrome 打开网址。
2. 点右上角的三个点。
3. 选「添加到主屏幕」或「安装应用」，确认即可。

## 数据保存说明

- 所有记录和照片都保存在**这台手机的这个浏览器**里，不会上传到网上，换设备、换浏览器都看不到。
- 清理浏览器缓存、卸载浏览器、iPhone 长期不用 Safari 可能导致数据被系统清掉，请定期用「设置 → 导出备份」存一份 JSON 文件。
- 照片是压缩后存进浏览器的，浏览器给单个网站的存储空间通常只有几 MB 到几十 MB，页面里的「存储空间」一条会显示已用多少。存不下了会提示你，删掉旧照片或者先导出备份。
- 换新手机：旧手机导出 JSON → 把文件传到新手机 → 新手机打开网页 → 设置 → 选择备份文件。

## 小技巧

- 电脑上打开时：按 `N` 新建，`Ctrl + K` 搜索，在编辑框里 `Ctrl + Enter` 保存，`Esc` 关闭照片预览。
- 点记录里的小照片可以直接放大看，左右滑动切换。

## 本地预览（可选）

在本文件夹里打开命令行，运行 `python -m http.server 8000`，然后浏览器访问 `http://localhost:8000/`。直接用双击打开 `index.html` 也能用，只是离线缓存不会生效。
